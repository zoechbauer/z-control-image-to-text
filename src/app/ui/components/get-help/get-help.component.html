What can the app do?

What is this app for?

Make a photo or load an image from your device, and the app will extract the text from the image using Optical Character Recognition (OCR) technology.

The extracted text together with an entered title and description can be copied to clipboard or saved to your device.

The app also provides statistics about the extracted text, including word count, line count, and character count.

You can choose the base language (English or German) in the settings.

Highlights:

  • Extract text and add information
    The photo and the extracted text can be displayed, and a title and description can be added and saved on the device.
  • Manage history
    You can view and manage the history of images with the extracted text and the added information.
  • Copy captured info, extracted text and photo
    You can then easily share this information by pasting the copied content into another app.
  • Status indicator
    This always shows the next processing step.

Limitations:

  • Shared free monthly quota: {{ maxFreeFeatureCharsLengthPerMonth | number: "1.0-0" : "de" }} characters for all users If this quota is exceeded, z-control incurs costs.

    Therefore, available options are limited to prevent the shared monthly quota from being used up too quickly.

    At the end of the feature page, your current feature quota is shown in the Monthly quota section. You can expand or collapse this section.

Troubleshooting & Problem Solving

  • Why do I get "Storage Permission Required" error and how do I fix it?

    If you see this error when saving or mailing images, you need to grant storage permissions to the app:

    Solution:

    1. Go to Settings
    2. Select Apps
    3. Find z-control Image to Text
    4. Tap Permissions
    5. Enable Storage permission

    This error typically occurs on older Android versions (e.g., Android 9). When you first start the app, you'll be asked to allow permissions to access photos, media, and files. If you previously denied permissions and selected "Don't ask again", you'll get this error and need to manually enable them in your device settings.

    On certain devices, such as Samsung Galaxy S8/S9 models, it may still not work despite these settings. In that case, please use the web version of this app.

Was kann die App?

Wofür ist diese App gedacht?

Machen Sie ein Foto oder laden Sie ein Bild von Ihrem Gerät, und die App extrahiert den Text aus dem Bild mithilfe der optischen Zeichenerkennung (Optical Character Recognition, OCR).

Der extrahierte Text kann zusammen mit einem eingegebenen Titel und einer Beschreibung kopiert oder auf Ihrem Gerät gespeichert werden.

Die App bietet außerdem Statistiken zum extrahierten Text, einschließlich Wortanzahl, Zeilenanzahl und Zeichenanzahl.

Die Basissprache (Englisch oder Deutsch) können Sie in den Einstellungen auswählen.

Highlights:

  • Text extrahieren und Informationen ergänzen
    Das Foto und der extrahierte Text können angezeigt und Titel und Beschreibung ergänzt und auf dem Gerät gespeichert werden.
  • Historie verwalten
    Sie können die Historie der Bilder mit dem extrahierten Text und den ergänzten Informationen einsehen und verwalten.
  • Erfasste Info, extrahierten Text und Foto kopieren
    Sie können diese Informationen dann sehr einfach teilen, indem Sie die kopierten Informationen in eine andere App einfügen.
  • Statusanzeige
    Damit wird immer der nächste Verarbeitungsschritt angezeigt.

Einschränkungen:

  • Gemeinsames kostenloses Monatskontingent: {{ maxFreeFeatureCharsLengthPerMonth | number: "1.0-0" : "de" }} Bild-Verarbeitungen für alle Nutzer Wird dieses Kontingent überschritten, entstehen für z-control Kosten.

    Daher ist die Auswahl begrenzt, damit das gemeinsame Monatskontingent nicht zu schnell aufgebraucht wird.

Fehlerbehebung & Problemlösung

  • Warum erhalte ich die Fehlermeldung "Speicherberechtigung erforderlich" und wie behebe ich das?

    Falls beim Speichern oder Versenden von Bildern dieser Fehler auftritt, müssen Sie der App Speicherberechtigungen erteilen:

    Lösung:

    1. Gehen Sie zu Einstellungen
    2. Wählen Sie Apps
    3. Suchen Sie z-control Image to Text
    4. Tippen Sie auf Berechtigungen
    5. Aktivieren Sie die Speicherberechtigung

    Dieser Fehler tritt typischerweise bei älteren Android-Versionen (z.B. Android 9) auf. Beim ersten Start der App werden Sie gefragt, ob Sie Berechtigungen für den Zugriff auf Fotos, Medien und Dateien erteilen möchten. Falls Sie zuvor die Berechtigung verweigert und "Nicht mehr fragen" ausgewählt haben, erhalten Sie diese Fehlermeldung und müssen die Berechtigung manuell in den Geräteeinstellungen aktivieren.

    Bei bestimmten Geräten, wie zum Beispiel dem Samsung Galaxy S8/S9, kann es vorkommen, dass es trotz korrekter Einstellungen weiterhin nicht funktioniert. In diesem Fall nutzen Sie bitte die Web-Version dieser App.
