What can the app do?

With z‑control Image to Text, you can take a photo or select an image from your device. The app recognizes the text contained in the image using optical character recognition (OCR) and then displays it.

You can add a title and a description to the recognized text. The information can then be copied, pasted into other apps, or shared.

The following data is automatically stored locally on your device: the image, the recognized text, the title, the description, and the creation and modification dates. The data is not stored in the cloud.

You can view, edit, copy, share, or delete saved entries at any time.

The app also provides statistics for the recognized text, including the number of words, lines, and characters.

You can choose German or English as the app language.

Features at a glance:

  • Recognize text in images
    Take a photo or select an existing image. The app recognizes the text contained in the image and displays the result.
  • Add additional information
    Add a title and a description to the entry.
  • Manage history
    View previously processed images and their associated information. You can edit or delete individual entries or the entire history.
  • Copy and share data
    Choose whether you want to copy or share the image, title, description, recognized text, text statistics, and creation and modification dates.
  • Status display
    The status display guides you step by step through the processing procedure.

Free quota limitation:

    Text recognition uses the paid Google Cloud Vision API. Therefore, only a limited free quota is available each month.

    The app informs you in good time when the quota is approaching its limit. Once the available quota for the current month has been used up, no further images can be processed.

    You can still view, edit, copy, share, and delete previously processed images and their associated information.

Technical information

z‑control Image to Text uses optical character recognition (OCR) to recognize text in images and convert it into machine-readable text. This allows you to process, for example, photos of documents, scanned documents, or other images containing text.

The app uses the Google Cloud Vision API for text recognition. The API supports image formats including JPEG and PNG.

The app uses the document_text_detection feature to recognize text in documents. This feature is designed for documents and images containing larger amounts of text. It can process complex layouts, multiple text columns, and different fonts.

The selected or captured image is transmitted to the Google Cloud Vision API for processing. The API analyzes the image and returns the recognized text to the app. The image, the recognized text, and any additional information you provide are then stored locally on your device.

The stored data is not automatically synchronized with a cloud service. When you copy or share data, you decide which other app or recipient receives the data.

For more information about text recognition, see the Google Cloud Vision API documentation .

Costs and free quota

Use of the Google Cloud Vision API may incur costs depending on the number of images processed and the feature used. The document_text_detection feature includes a limited free quota. Charges may apply after the free quota has been used.

To help prevent unexpected costs, the app uses a shared monthly quota for all users. The app monitors usage of this quota and prevents further image processing once the available quota for the current month has been exhausted.

The quota is automatically reset on the first day of the following month. Previously processed images and their associated information remain available locally on your device.

For current prices and free-quota conditions, see the Google Cloud Vision API pricing page .

Actual costs may change if Google updates the API's prices, features, or service conditions. To manage costs, monitor your usage and consider setting up billing alerts in Google Cloud.

Troubleshooting

  • Why can't I copy the image?

    JPEG images currently cannot be copied to the clipboard in the web version. Therefore, the checkbox for the image is disabled in the selection dialog.

    A JPEG image may be created when you:

    • select a JPEG image from the gallery, or
    • open the web version on a mobile device and take a photo with the camera.

    If you use the web version on a PC or notebook and take a photo with the camera, a PNG image is normally created. This image can be copied.

    On a mobile device, you can currently only copy and share text information in the web version. However, text recognition itself also works in the web version.

    To use the full range of functions on a mobile device, please use the native app.

  • Why is the error message “Storage permission required” displayed?

    If this error message appears when saving or sharing an image, the app requires an additional permission.

    How to enable the permission:

    1. Open your device's settings.
    2. Select “Apps”.
    3. Search for “z‑control Image to Text”.
    4. Open the “Permissions” section.
    5. Allow access to photos or storage.

    This problem occurs especially on older Android versions. If you previously denied a permission and also selected “Don't ask again”, you must enable the permission manually in your device's settings.

    On some older devices, including certain Samsung Galaxy models, access may still fail despite the correct settings. In this case, please use the web version of the app.

Technische Informationen

z‑control Image to Text verwendet optische Zeichenerkennung (OCR), um Text aus Bildern zu erkennen und in maschinenlesbaren Text umzuwandeln. Dadurch können beispielsweise Fotos von Dokumenten, gescannte Unterlagen oder andere Bilder mit enthaltenem Text verarbeitet werden.

Für die Texterkennung verwendet die App die Google Cloud Vision API . Die API unterstützt unter anderem Bilder im JPEG- und PNG-Format.

Für die Erkennung von Text in Dokumenten verwendet die App die Funktion document_text_detection. Diese Funktion ist für Dokumente und Bilder mit umfangreichen Textinhalten geeignet und kann unter anderem komplexe Layouts, mehrere Textspalten und unterschiedliche Schriftarten verarbeiten.

Das ausgewählte oder aufgenommene Bild wird zur Verarbeitung an die Google Cloud Vision API übertragen. Die API analysiert das Bild und liefert den erkannten Text an die App zurück. Anschließend werden das Bild, der erkannte Text sowie Ihre zusätzlichen Informationen lokal auf Ihrem Gerät gespeichert.

Die gespeicherten Daten werden nicht automatisch in einer Cloud synchronisiert. Wenn Sie Daten kopieren oder teilen, entscheiden Sie selbst, an welche andere App oder welchen Empfänger die Daten weitergegeben werden.

Weitere Informationen zur Texterkennung finden Sie in der Dokumentation der Google Cloud Vision API .

Kosten und kostenloses Kontingent

Die Nutzung der Google Cloud Vision API ist abhängig von der Anzahl der verarbeiteten Bilder und der verwendeten Funktion kostenpflichtig. Für die Funktion document_text_detection steht ein begrenztes kostenloses Kontingent zur Verfügung. Nach dessen Verbrauch können Kosten entstehen.

Um unerwartete Kosten zu vermeiden, verfügt die App über ein begrenztes gemeinsames Monatskontingent für alle Nutzer. Die App überwacht die Nutzung dieses Kontingents und verhindert weitere Bildverarbeitungen, sobald das verfügbare Kontingent im laufenden Monat aufgebraucht ist.

Das Kontingent wird am ersten Tag des folgenden Monats automatisch zurückgesetzt. Bereits verarbeitete Bilder und die zugehörigen Informationen bleiben weiterhin auf Ihrem Gerät verfügbar.

Die aktuellen Preise und die Bedingungen des kostenlosen Kontingents finden Sie auf der Preisseite der Google Cloud Vision API .

Die tatsächlichen Kosten können sich ändern, wenn Google die Preise, Leistungsmerkmale oder Bedingungen der API anpasst. Für die Verwaltung der Kosten empfiehlt es sich, die Nutzung zu überwachen und gegebenenfalls Abrechnungswarnungen in Google Cloud einzurichten.

Fehlerbehebung und Problemlösung

    JPEG-Bilder können in der Web-Version derzeit nicht in die Zwischenablage kopiert werden. Deshalb ist das Kontrollkästchen für das Bild in der Auswahlmaske deaktiviert.

    Ein JPEG-Bild kann entstehen, wenn Sie:

    • ein JPEG-Bild aus der Galerie auswählen oder
    • die Web-Version auf einem Mobilgerät öffnen und dort ein Foto mit der Kamera aufnehmen.

    Wenn Sie die Web-Version auf einem PC oder Notebook verwenden und dort ein Foto mit der Kamera aufnehmen, wird normalerweise ein PNG-Bild erzeugt. Dieses Bild kann kopiert werden.

    Auf einem Mobilgerät können Sie in der Web-Version derzeit nur die Textinformationen kopieren und teilen. Die Texterkennung selbst funktioniert jedoch auch in der Web-Version.

    Für den vollständigen Funktionsumfang auf einem Mobilgerät verwenden Sie bitte die native App.

  • Warum wird die Fehlermeldung „Speicherberechtigung erforderlich“ angezeigt?

    Wenn beim Speichern oder Teilen eines Bildes diese Fehlermeldung erscheint, benötigt die App eine zusätzliche Berechtigung.

    Berechtigung aktivieren:

    1. Öffnen Sie die Einstellungen Ihres Geräts.
    2. Wählen Sie „Apps“.
    3. Suchen Sie nach „z‑control Image to Text“.
    4. Öffnen Sie den Bereich „Berechtigungen“.
    5. Erlauben Sie den Zugriff auf Fotos beziehungsweise Speicher.

    Dieses Problem tritt insbesondere bei älteren Android-Versionen auf. Wenn Sie eine Berechtigung zuvor abgelehnt und zusätzlich „Nicht mehr fragen“ ausgewählt haben, müssen Sie sie manuell in den Geräteeinstellungen aktivieren.

    Bei einigen älteren Geräten, beispielsweise bestimmten Samsung-Galaxy- Modellen, kann der Zugriff trotz korrekter Einstellungen weiterhin fehlschlagen. Verwenden Sie in diesem Fall bitte die Web-Version der App.
