# Tool Templates (Reference)

These tool templates were originally used for the z-control Translator app.

Use them as reference templates when creating a new app from the z-control IONIC Setup app.

Important:

- Adapt all app-specific values for each new app (name, text, links, colors, logos, and assets).
- Do not reuse Translator-specific content unchanged for production releases.

Included templates:

- bg-color.txt
- feature-graphic-template-DE.html
- feature-graphic-template-EN.html
- fullsize-splash-creator.html
- google-play-icon-template.html
- splash-creator.html
- splash-screen-template.html
